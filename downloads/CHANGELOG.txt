开发中（2026-10-27）
============================================================
[新功能]
- Windows 与 Linux 运行包内置全部常见数据库驱动（MySQL/MariaDB、PostgreSQL 协议系国产库、SQL Server、Oracle、达梦、Redis、MongoDB），无需用户再单独安装驱动包。

[修复]
- 修复 Windows 运行包缺少 SQL Server 驱动（pyodbc）导致连接时提示“缺少 SQL Server 驱动包”的问题。
- 修复 SQL Server 连接中展开多个数据库时，后展开的库显示前一个库的表、视图、列等对象的问题。
- 修复 SQL Server 数据网格无法新增、修改、删除数据的问题：事务语句改为 T-SQL 的 BEGIN/COMMIT/ROLLBACK TRANSACTION。
- 修复 Windows 运行包连接 SQL Server 时报“The driver did not supply an error!”的问题：打包时改用系统较新的 VC++ 运行库（MSVCP140/VCRUNTIME140），避免 ODBC Driver 18 加载到 PyQt5 自带的旧版本。

[改进]
- Linux 构建产物按 GDDBStudio 版本、统信/麒麟发行版版本和 CPU 架构独立归档，生成可直接分发的免安装压缩包及构建信息。
- 兼容 UOS ARM64 的 Conda-forge PySide6 构建环境，并从 Conda 包缓存和 UOS 系统路径收集许可证文本。

- 修复“查看更新”在开发环境下错误计算项目根目录、导致找不到 CHANGELOG.txt 的问题。
- 更新日志路径统一兼容开发环境和 PyInstaller 打包环境。

版本 0.6.0（2026-08-20）
============================================================
[新功能] 全面支持主流国产（信创）数据库，共 12 种：
- 达梦 DM8（专用驱动 dmPython，Oracle 风格数据字典 + DM 方言 DDL）
- 人大金仓 KingbaseES、openGauss、GaussDB、瀚高 HighGo、Vastbase 海量
  （PostgreSQL 协议系，复用 psycopg；openGauss/GaussDB 已适配 PG 9.2 内核的索引查询）
- OceanBase、TiDB、PolarDB、TDSQL、GoldenDB、GBase 8a
  （MySQL 协议系，复用 PyMySQL；information_schema 列不齐时自动降级兼容）
- 新建连接向导新增"国产信创"筛选标签，可一键筛出全部国产库；
  URI 新建连接支持 dm://、opengauss://、oceanbase://、tidb:// 等 scheme。
- 各产品自动预填默认端口/用户/初始库（如达梦 5236/SYSDBA、
  KingbaseES 54321/test、OceanBase 2881、TiDB 4000）。

[改进]
- SQL 美化方言、表设计器"选项"页改由驱动注册表声明，后续新增数据库
  无需修改任何 UI 代码。

[修复]
- 修复打包后右键菜单全部失效：迁到 PyQt5 后 @Slot() 声明的是零参数槽，
  而连接树/数据网格/表设计器的右键处理函数需要接收 QPoint，PyQt5 不传参
  导致 TypeError 被静默吞掉。已修正全部同类槽的参数签名。
- 打包时禁用 UPX 压缩（--noupx），避免 Qt DLL 被压缩后弹出类窗口异常。

版本 0.5.1（2026-08-12）
============================================================
[新功能]
- 主窗口「帮助」菜单新增「更新日志」，可查看本文件内容。
- 关于对话框显示当前版本号。
- 数据网格支持查找/替换（Ctrl+F / Ctrl+H），仿 Navicat 在表数据底部打开查找条。
- 连接树右键支持转储 SQL 文件（结构和数据 / 仅结构）。
- 支持从 Navicat 注册表导入连接（Navicat 12+ AES 解密）。
- SQL 编辑器支持撤销、重做、查找、替换。
- 主窗口任务栏图标修复、表设计器文本截断修复。
- 增加 PyInstaller 打包脚本与 Windows 单机 exe 构建。

[修复]
- 修复 SQL 编辑器撤销/重做测试因 setPlainText 绕过撤销栈导致的偶发失败。
- 修复数据网格查找范围误作用于 SQL 编辑器的问题，改为仅作用于 DataGridTab。
