A CLOSER LOOK

不是概念图。是你的下一个工作台。

从连接到结果，亲眼看看每一步。所有截图均来自软件实际界面，可点击放大。

1. 新建连接

工具栏点击“新建连接”，在数据库类型列表中选择目标数据库（支持按“国产信创”筛选），填写主机、端口、用户名和密码，点击“测试连接”成功后保存。

  • 可通过 URI 快速新建连接
  • 支持 SSL 加密连接与 SSH 隧道
  • 支持设置连接颜色，区分生产与测试环境

2. 数据浏览与编辑

双击表名即可打开数据网格，分页浏览大数据量表，支持跳页、刷新、筛选条件和查找替换。单元格可直接编辑，修改可在事务中统一提交或撤销。

  • 可视化构建筛选条件，也可直接编写原始 WHERE 表达式
  • 支持新增、删除、设为 NULL，删除操作可开启确认提示

3. SQL 编辑器

新建查询标签页，编写 SQL 后可整段或选中部分执行，结果以表格形式展示，多条语句会生成多个结果集。

  • 语法高亮与自动完成，支持撤销、重做、查找替换
  • 一键美化 SQL，执行历史与已保存查询随时找回

4. 表结构设计

在表设计器中查看与修改字段、索引、外键、触发器和表选项。所有修改先生成 DDL 并展示给你确认，确认后才会执行。

5. 数据导入、导出与传输

CSV 文件可按字段映射批量导入并预览前几行；数据可导出为 CSV、SQL 或 Excel；还能把数据从一个连接直接传输到另一个连接。

6. 个性化设置

可以设置界面主题、界面字体和编辑器字体，并配置自动提交、删除确认、信息面板显示以及查询结果行数上限，按自己的习惯使用。

第一次使用？从这份快速入门开始。+
  1. 下载对应系统的安装包，解压到任意目录，双击运行 GDDBStudio.exe（Windows）或目录内的 GDDBStudio 程序（Linux）。
  2. 点击工具栏 新建连接，选择数据库类型。
  3. 填写主机、端口、用户名和密码，或选择 SQLite 数据库文件。
  4. 点击 测试连接，成功后点击 确定。
  5. 在左侧双击连接，展开数据库和表节点，双击表名查看数据。
  6. 点击 新建查询，编写并执行 SQL。

想先熟悉软件，可以选择 SQLite，无需部署数据库服务，也无需填写主机和端口。

LOCAL FIRST. CLEAR BY DESIGN.

本地优先，保护方式说清楚。

不夸大安全承诺。了解不同系统的密码保护方式，再选择适合你的使用策略。

Windows 版密码保护

保存的数据库密码使用 Windows DPAPI 进行本地保护，绑定当前 Windows 用户和计算机。连接配置文件复制到其他机器或其他 Windows 账号下无法解密密码。

Linux 版密码保护

Linux 版当前为降级保护，仅适合开发调试环境。在生产或高安全级别场景下，建议不勾选“保存密码”，每次连接时手动输入。

本地优先

连接配置、界面设置、SQL 执行历史和运行日志默认保存在本机，软件不进行外部网络上报。

最小权限建议

建议为软件使用的数据库账号分配所需的最小权限；对生产库可使用只读连接，降低误写入风险。
